# Honours SpellChecker Project

This repository contains the Jupyter Notebook (`SpellChecker.ipynb`) for my Honours project on NLP-based spell checking for isiZulu.

## Dataset
Due to GitHub file size limits, the dataset (`Corpora.zip`) is hosted on Google Drive. 
You can download it here: [https://drive.google.com/file/d/1D1LCXwWWLh9kADtsZUN18IBX9TBZSbJ3/view?usp=sharing]

## How to Run
1. Download the dataset from the link above.
2. Open `SpellChecker.ipynb` in Google Colab or Jupyter.
3. Ensure all dependencies listed in the first cell are installed.
